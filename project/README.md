# 🃏 Yu-Gi-Oh! Card Creator

Projeto desenvolvido com **HTML, CSS e JavaScript** para criar e personalizar cartas inspiradas no universo de Yu-Gi-Oh!.

## ✨ Funcionalidades

- Criar cartas personalizadas
- Editar nome, atributos e informações da carta
- Interface inspirada no jogo original
- Entretenimento ao público
